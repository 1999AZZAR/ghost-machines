← Ghost Machines · Tenant WaaS

Multi-tenant Workspace-as-a-Service

One host → many isolated workstations. Each tenant: mounts/tenants/<id> + own SSH port (auto from 2225) + CPU/RAM quotas + snapshots.

Prebuilt (fast)

docker pull ghcr.io/1999azzar/ghost-machine-debian:latest
./tenant.sh add alice --engine debian --cpu 2 --mem 4G --port 2225
./tenant.sh add bob --engine ubuntu --cpu 4 --mem 8G

Build locally

./tenant.sh add alice --engine debian --build
./tenant.sh list · ./tenant.sh stats · ./tenant.sh delete alice -y

See index#tenant and tenant.sh for full flags.
