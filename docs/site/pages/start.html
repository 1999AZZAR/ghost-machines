Step-by-step — Beginner & Casual

Beginner (plain)

  1. git clone https://github.com/1999AZZAR/ghost-machines.git && cd ghost-machines
  2. make setup-host (once, Linux)
  3. docker pull ghcr.io/1999azzar/ghost-machine-ubuntu:latest
  4. GHOST_IMAGE=ghcr.io/1999azzar/ghost-machine-ubuntu:latest ./start.sh -e ubuntu -m single
  5. ssh -p 2223 developer@localhost — pass ghost
  6. Work in mounts/ — container can be deleted, work stays.

Casual (knows Docker)

GHOST_IMAGE=ghcr.io/1999azzar/ghost-machine-ubuntu:latest ./start.sh -e ubuntu -m dual # 2×1c/8G
./start.sh --no-lxcfs -p 2225 --build # custom port, rebuild
Modes: dual/single/power(2c/16G)/half(50% host)

Cleanup: ./clean.sh --nuke -y (Level 4 full purge).
