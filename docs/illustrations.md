# Illustration shot list

One 16:9 Blotcat illustration per documentation page. Generated through the
`blotcat-illustrations` skill and written to `docs/site/assets/blotcat/`; the
builder renders the declared figure under each page header.

Style contract for every image: 16:9 horizontal body illustration, pure white
background, black hand-drawn line art, solid black Blotcat (white dot eyes,
thin legs, blank expression) doing the core action, 3–5 sparse red/orange/blue
handwritten English annotations, generous white space, no PPT/flowchart look,
no corner title, no cute style.

## Generation notes

Plates are raster PNGs generated by an agent that reads this skill's own
references (`style-dna.md`, `blotcat-ip.md`, `composition-patterns.md`,
`prompt-template.md`, `qa-checklist.md`) and then generates each image
individually — hand-drawn wobble, sparse colour, Blotcat performing the core
action — and checks it against the QA list before saving.

Two providers were attempted first and both hit hard limits: `agy`'s image
model returned `429 RESOURCE_EXHAUSTED` (multi-hour reset, twice) and the
OpenRouter image endpoint returned `402` ("at least $1.00 balance for image
output"). Codex, driven through herdr with the skill, produced the final set.
Regenerate a single plate by re-running the same instruction for that row.
